# Raiz & Brasa — template_rest

Site demonstrativo modular para restaurantes, desenvolvido em PHP 8.1+ e MySQL 8.0+.

Módulos planejados: catálogo, pedidos, pagamentos, reservas, entregas e painel administrativo.

> Ambiente demonstrativo. Nenhum pagamento real é processado sem configuração explícita de provedor e webhook validado.

Consulte `docs/INSTALL.md` e `docs/MODULES.md` para instalação e arquitetura.

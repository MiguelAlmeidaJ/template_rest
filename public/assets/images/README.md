# Substituição de fotos sem modificar código

Coloque suas fotos nesta pasta, mantendo estes nomes em JPG:
- hero.jpg — capa principal, recomendado 1800 × 1100
- ambience.jpg — imagem de ambiente, 1000 × 1100
- reservation.jpg — imagem da página de reservas, 1000 × 1300
- dish1.jpg, dish2.jpg, dish3.jpg, dish4.jpg — pratos, recomendado 900 × 700

Os nomes abaixo também são usados na listagem do cardápio pela ordem da API.
Caso o arquivo local não exista, a página carrega imagens demonstrativas do Unsplash.
Para produção, utilize imagens próprias ou licenciadas e mantenha dados dos pratos sincronizados.
